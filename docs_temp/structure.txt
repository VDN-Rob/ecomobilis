There are two sides of the application. The user side (ecomobilis) and the administrators side (ecomobilis-admin).
They share the same database.
The admin side controls the data in the database. -> You need to change the admin application if the new external carpool provider changes what your administrators need to manage in the database.

* The API - Controllers and Resources
* The database - Models
* The business logic - Events, Listeners and Jobs
* The Notifications - Mail
