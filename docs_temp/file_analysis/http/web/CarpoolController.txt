Controller => receive requests from the website and decide what to do next

User clicks "Search" -> Laravel route -> CarpoolController@matching() -> CarpoolRide@getMatchingRides() -> Database -> Blade view -> Results shown to user

| Method         | Purpose                       |
| -------------- | ----------------------------- |
| `overview()`   | Show upcoming rides           |
| `matching()`   | Search for matching rides     |
| `show()`       | Show one specific ride        |
| `create()`     | Show form for creating a ride |
| `store()`      | Actually create the ride      |
| `edit()`       | Show form for editing a ride  |
| `update()`     | Actually update the ride      |
| `cancelRide()` | Cancel a ride                 |


2. matching()

$request->validate([
            'DepJson' => 'required',
            'ArrJson' => 'required',
            'travel_start_datetime' => 'required',
        ]);

=> request needs to have a departure json, arrival json and a travel date and time

DepJson -> CarpoolStreetCoordinate -> departure latitude/longitude

ArrJson -> CarpoolStreetCoordinate -> arrival latitude/longitude


We have:

Website -> CarpoolController::matching() -> CarpoolRide::getMatchingRides() -> carpool_rides + carpool_street_coordinates -> Matching rides -> Blade

Will have to change to:
Website -> CarpoolController::matching() -> BlaBlaCar service -> BlaBlaCar API -> Matching BlaBlaCar rides -> Blade
