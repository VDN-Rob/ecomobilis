4. Mapping
travel_start_datetime -> When the ride starts
from_street_coordinates_id -> Departure location
to_street_coordinates_id -> Arrival location
luggage_id -> Luggage information
seats_available -> Available seats
remark -> Driver's comment
price_per_seat -> Price
user_id -> User/driver associated with ride
group_id -> Carpool group
is_private -> Whether ride is private
is_cancelled -> Whether ride was cancelled

{
    return $this->belongsToMany(
        User::class,
        'carpool_rides_reservations',
        'ride_id',
        'passenger_user_id'
    )->where('is_accepted', 1);

CONCLUSION:
The current Ecomobilis carpool system owns:

Ride creation -> CarpoolRide
Ride location -> CarpoolStreetCoordinate
Driver/user -> User
Vehicle-related information -> CarpoolCar/CarpoolCarType
Luggage -> CarpoolLuggage
Groups -> CarpoolGroup
Reservations -> CarpoolRideReservation
Messaging -> CarpoolMessage
Ride searching -> getMatchingRides()
Ride cancellation -> is_cancelled
Private rides -> is_private
Notifications -> Events + listeners + mail
